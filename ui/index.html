Poserpose rigs for Rive

Bind

Key the origin on frame 0 and the four extremes on frames 1–4, keying every property on every pose. Add a joystick (J) to the artboard, then bind. The panel bakes each pose into a formula, so the rig runs with no script.

Ease bias

−100 eases in, +100 eases out, 0 is linear (per direction, like J&S EaseBias).

L0 R0 U0 D0

Bind

The origin goes on frame 0 and one pose on each following frame. Each pose becomes a slider (0–100) in the artboard's view model, and sliders add together like blend shapes.

UI slider

Drive a slider from a joystick axis, so it can be dragged and keyed on the canvas.

Switch

Select the swap items (mouths, noses…). Each one gets a spot on the joystick (−1 to 1, y down), and only the item nearest the joystick stays visible.

Pose tools

Key all keys every animatable number on the selection. Paste origin copies frame 0 to the frame above. Unkey flat removes tracks that never change across the pose frames.

PathFlipper

Mirrors the selected path around its first vertex.
